4D Receipt — Privacy Policy

Effective date: November 2026 · 4D Suite

The short version

Everything 4D Receipt captures — page snapshots, diffs, visit counters — is stored locally on your device, encrypted with AES-256-GCM, and never transmitted anywhere. There is no server, no account, no analytics, no tracking. The only network request the extension can ever make is an optional, user-enabled anchor post that sends a hash (Merkle root) — never content.

What the extension reads, and what it never reads

  • It reads visible article text of pages you visit, for change detection.
  • It never reads, stores, or transmits anything you type: form fields, inputs, passwords, and editable areas are structurally excluded from extraction.
  • It never sells, shares, or syncs data. Wipe deletes the encryption key — recovery is impossible by design.

The broad permission, explained

4D Receipt requests access to all websites because a change-log tool cannot detect changes on pages it cannot read. The permission grants read access to rendered text only; the code enforces the exclusions above and the extension declares no remote code and no remote servers.

Open source

4D Receipt is MIT-licensed; its source is publicly available for audit.
